# Nightly Channel

> Try the latest Fastnode changes before they are released, with builds published automatically for every commit to the `main` branch.

You can opt in to the nightly release channel by updating your `package.json`:

```json
{
  "devDependencies": {
    "fastnode": "npm:fastnode-nightly@latest"
  }
}
```

Remove the lockfile (`package-lock.json`, `yarn.lock`, `pnpm-lock.yaml`, `bun.lock`, or `bun.lockb`) and reinstall the dependencies.

When using **Bun as package manager** in a mono-repo, you need to make sure fastnode package is properly hoisted:

```toml [bunfig.toml]
[install]
publicHoistPattern = ["fastnode*"]
```

Avoid using `<npm|pnpm|yarn|bun|deno> install fastnode-nightly`; it does not install correctly.
If you encounter issues, delete your `node_modules` and lock files, then follow the steps above.

Migrating from Fastnode v1 at the same time? See the [migration guide](/docs/migration).
