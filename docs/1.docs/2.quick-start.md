# Quick Start

> Start with a fresh Fastnode project or adopt it in your current Vite project.

## Try Fastnode online

Get a taste of Fastnode in your browser using our playground.

[Play with Fastnode in StackBlitz](https://stackblitz.com/github/khulnasoft/starter/tree/v3-vite?file=index.html,server.ts){target="_blank"}

## Create a Fastnode project

The fastest way to create a Fastnode application is with the `fastnode create` command.

> [!NOTE]
> Make sure you have the latest LTS version of [Node.js](https://nodejs.org/en) or [Bun](https://bun.sh/) installed.

::code-group
```sh [npm]
npx --min-release-age=0 fastnode@latest create
```
```sh [pnpm]
pnpm dlx --config.minimum-release-age=0 fastnode@latest create
```
::

::note
The `--min-release-age=0` (npm) and `--config.minimum-release-age=0` (pnpm) flags skip any minimum release age you have configured, so you always get the latest Fastnode release.
::

Follow the CLI instructions and you will be ready to start your development server. See [`fastnode create`](/docs/cli#fastnode-create) for all options.

## Add to a Vite project

You can add Fastnode to any existing Vite project to get API routes, server-side rendering, and more.

::steps{level="3"}

### Install `fastnode` and `vite`

:pm-install{name="fastnode vite"}

### Add Fastnode plugin to Vite

Add the Fastnode plugin to your `vite.config.ts`:

```ts [vite.config.ts] {2,6}
import { defineConfig } from "vite";
import { fastnode } from "fastnode/vite";

export default defineConfig({
  plugins: [
    fastnode()
  ],
});
```

### Configure Fastnode

Create a `fastnode.config.ts` to configure the server directory:

```ts [fastnode.config.ts]
import { defineConfig } from "fastnode";

export default defineConfig({
  serverDir: "./server",
});
```

The `serverDir` option tells Fastnode where to look for your server routes. In this example, all routes will be inside the `server/` directory. By default `serverDir` is `false`, so no directories are scanned until you set it (or `scanDirs`).

### Create an API route

Create your first API route at `server/api/test.ts`:

::code-tree{defaultValue="server/api/test.ts"}
```ts [server/api/test.ts]
import { defineHandler } from "fastnode";

export default defineHandler(() => {
  return { message: "Hello Fastnode!" };
});
```
```ts [fastnode.config.ts]
import { defineConfig } from "fastnode";

export default defineConfig({
  serverDir: "./server",
});
```
```ts [vite.config.ts]
import { defineConfig } from "vite";
import { fastnode } from "fastnode/vite";

export default defineConfig({
  plugins: [fastnode()],
});
```
::

The file path maps directly to the route URL: `server/api/test.ts` becomes `/api/test`. Handlers can return strings, JSON objects, `Response` instances, or readable streams.

::tip
As an alternative to filesystem routing, you can declare routes programmatically using the `routes` config option. See [Programmatic route handlers](/docs/routing#programmatic-route-handlers) for more details.
::

### Start the development server

:pm-run{script="dev"}

Your API route is now accessible at `http://localhost:3000/api/test` :sparkles:

::
